# TY/LY weekly dashboard (web)

Static React app (Vite + TypeScript) that shows how the business is performing week by week, with an AI briefing whose every number is checked against the data. Design: Claude Design "TYLY Dashboard" (Sapphire / Charcoal / Thistle, Archivo + Space Mono).

## Run locally
```bash
npm install
npm run dev        # http://localhost:5199
npm run verify     # browser validator == Python validator on every AI text
npm run build      # → dist/
```
The data file `src/data/app.json` is generated by the Python pipeline (`../run_all.sh`, script `18_export_web.py`) and committed, so the web build needs no Python.

## Deploy (Vercel)
Import the GitHub repo in Vercel and set **Root Directory = `web`**. `vercel.json` sets the framework (Vite), the build command (`npm run verify && npm run build`, so a deploy fails if any AI number doesn't validate) and the output directory (`dist`). No environment variables or API keys are needed.

## What's where
| Path | What |
|---|---|
| `src/lib/core.ts` | design tokens, formatting (display only), data access, URL state, motion preference |
| `src/lib/validator.js` | number validator (port of `scripts/17_validate_summaries.py`) |
| `src/components/Header.tsx` | nav, search, week strip, window + LY controls, hero, KPI band |
| `src/components/Briefing.tsx` | AI summary with live number check (M8), flagged cards, rules + alerts rail |
| `src/components/Explore.tsx` | G1 playhead (M1), G2 morph (M5), G3 drill-down (M3), G4 scatter + WOS morphs (M5), tables |
| `src/components/Ask.tsx` | template Q&A |
| `src/components/HowBuilt.tsx`, `LikeForLike.tsx` | pipeline, prompts, definitions; naive vs like-for-like switch (M6) |
| `scripts/parity.mjs` | parity check run before every build |

Useful links: `#/briefing?wk=30` (partial week), `#/explore/g1` (press Play), `#/briefing?wk=29&demo=blocked` (validator holding back a wrong number).
