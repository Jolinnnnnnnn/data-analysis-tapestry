# metrics.json / anomalies.json schema

Generated by scripts/13_docs.py. Producer: scripts/11_metrics.py (metrics.json), scripts/12_anomalies.py (anomalies.json).

## Conventions
- `*_pct` and `yoy_pct`/`wow_pct` are FRACTIONS (0.128 = +12.8%). `chg_pts` and `contrib_pts` (in products_by_week) are percentage POINTS. `contrib_pts` in products_ptd is a fraction of LY total.
- `ty`/`ly` = FY26 / FY25. LY W30 is restricted to Sun–Wed to match TY (like-for-like, D3).
- Money in USD (sample scale). Counts are sample-scale; shares/ratios are the robust signal (D11).
- Ratios (aov, upt, aur, shares) are computed from totals for each window, never averaged.
- Shares: genz_share_of_new, genz_share_of_txns, returning_share, new_insider_rate, genz_new_insider_rate, outlet_share, ecomm_share → `{ty, ly, chg_pts}`.

## KPI keys (inside weekly / trailing / headline_ptd)

`sales`, `units`, `txns`, `customers`, `aov`, `upt`, `aur`, `new_customers`, `returning_customers`, `genz_txns`, `genz_new`, `genz_returning`, `genz_share_of_new`, `genz_share_of_txns`, `returning_share`, `new_insider_rate`, `genz_new_insider_rate`, `outlet_share`, `ecomm_share`

## anomalies.json

- `meta`: n_anomalies, counts_by_severity

- `by_week`: {'23': [ids], …}
